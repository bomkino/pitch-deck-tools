# Contributing

Thanks for being here.

This project is beginner-friendly by design. It is being built in public as a way to learn coding, GitHub, and practical tool-making through a real deck workflow.

## Good Contributions

- Make the tools easier to use.
- Improve documentation for non-coders.
- Fix bugs in the Mac workflow.
- Add small, focused features that help people make better pitch decks.
- Keep private assets, paid fonts, and client material out of the repo.

## Style

- Prefer simple code over clever code.
- Keep changes small.
- Explain tradeoffs when something could be done multiple ways.
- Avoid adding frameworks unless they clearly make the tool easier to maintain.

## Before Opening a Pull Request

- Make sure no private assets are included.
- Run the tool you changed locally.
- Describe what changed in plain language.
