# Roadmap

This project starts with three tools and can grow into a practical deck-making toolkit.

## Now

- Clean up the project structure.
- Keep one public GitHub repo.
- Document the tools for non-coders.
- Keep private assets out of the public repo.

## Next

- Add clean sample projects.
- Make export behavior clearer.
- Add basic tests for the Python scripts.
- Improve onboarding for people who have never used GitHub.
- Add screenshots and short demo videos.

## Later

- Make the tools more portable.
- Add reusable deck templates.
- Add better media organization workflows.
- Add visual critique/checklist helpers for pitch deck makers.
