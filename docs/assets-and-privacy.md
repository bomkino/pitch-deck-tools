# Assets and Privacy

This repo is meant to open-source the tools, not private work.

Do not commit:

- client pitch decks
- private scripts or treatments
- actor/cast reference images
- paid fonts
- downloaded design packs
- generated exports
- local thumbnails
- files with absolute local paths

The `.gitignore` file is intentionally conservative. It ignores private media, generated files, local deck state, and font binaries by default.

If the project needs demo assets later, they should go in a clearly named sample folder and use assets that are safe to redistribute.
